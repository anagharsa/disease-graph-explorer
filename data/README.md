# Source and transformation notes

Raw, unmodified source files belong in `data/raw/`. The acquisition script targets only the official HPO GitHub release `v2022-12-15` assets `hp.obo` and `phenotype.hpoa`. `data/source_manifest.json` tracks source page/asset URL, release identifier/date, retrieval date, terms, filename, SHA-256, and historical verification notes. Raw downloads are not committed.

`python scripts/validate_data.py` independently checks source file presence, ontology term and `is_a` counts, annotation row structure, phenotype references, and IDs matching COVID/SARS-CoV-2 patterns. It reports counts from files actually present; it does not manufacture records.

`python scripts/ingest_data.py` transforms OBO terms and HPOA rows into Neo4j. It keeps stable HPO IDs; preserves all named ontology terms including obsolete ones (marked `obsolete=true`); retains all `is_a` edges; parses synonyms and definitions; preserves association row details including qualifier (`NOT`), evidence, reference, onset, frequency, sex, aspect, and biocuration; filters only association rows whose phenotype ID has no matching term; and reports the skipped count. Identical rows at different file line positions remain separate Association nodes, so source record provenance is not collapsed. A stable SHA-256 over source row plus line number makes reruns idempotent.

The ontology and annotation inputs are separate from the imported graph and are never overwritten by normalization. No Mondo mappings, gene associations, inferred COVID features, or outside-release records are mixed into this build. Ingestion summary counts are created after a successful actual run.

HPO terms are available under HPO Consortium terms; acknowledge HPO and display file version/date as required. See the [HPO license page](https://human-phenotype-ontology.github.io/license.html). The selected HPOA disease sources are described by HPO's download docs as OMIM, Orphanet, and DECIPHER entries. The annotation set emphasizes rare and genetic disorders; common infections such as the common cold are not covered by this pinned source. The raw file audit found three rows for OMIM:301051, “Immunodeficiency 74, COVID19-related, X-linked,” and zero disease-name matches for a dedicated COVID-19/SARS-CoV-2 infection profile. This is not evidence for a COVID-19 infection phenotype profile.
